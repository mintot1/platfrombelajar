# Let Me Cook — Ruang Belajar & Kuis Interaktif

Platform web pembelajaran interaktif yang menyajikan rangkaian modul materi terstruktur (Sains, Teknologi, Matematika, Logika, Bahasa, Sejarah), dilengkapi dengan kuis soal pilihan ganda interaktif dan kalkulasi skor IQ dinamis di profil pengguna.

## Fitur Utama

- 🧠 **Rangkaian Materi Belajar & Kuis**: Eksplorasi materi berkualitas tinggi yang dapat langsung diuji pemahamannya lewat kuis soal interaktif.
- ⚡ **Kalkulasi Skor IQ Dinamis**: Skor IQ bertambah secara objektif berdasarkan jumlah materi yang dipelajari dan tingkat akurasi jawaban kuis.
- 📊 **Profil Pengguna Lengkap**: Pantau tingkat kecerdasan (IQ Tier), metrik pembelajaran, dan riwayat kuis yang diselesaikan.
- ✨ **AI Materi & Quiz Generator**: Buat modul belajar beserta latihan soal otomatis menggunakan Gemini AI.
- 🔗 **Import dari URL**: Rangkum artikel web edukasi menjadi ringkasan konsep dan kuis interaktif.
- 👥 **Kelompok Belajar (Study Squad)**: Bagikan materi dan kuis kepada teman belajar menggunakan Firebase Firestore.
- 🌓 **Desain Responsif & Dark Mode**: Tampilan estetik dengan palet warna stone, tipografi elegan, dan dukungan mode gelap/terang.

## Cara Menjalankan Lokal

1. **Instal dependensi:**
   ```bash
   npm install
   ```

2. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```

3. Buka browser di [http://localhost:3000](http://localhost:3000).

## Build Produksi

```bash
npm run build
```
